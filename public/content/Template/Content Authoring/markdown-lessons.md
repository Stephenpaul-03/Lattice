# Markdown Lessons

Lessons are ordinary markdown files. Write headings, paragraphs, lists, links, code blocks, and images without adding React components.

## Frontmatter

Optional frontmatter can set a title, a layout, or an MDN reference link. The page renderer uses it to decide how to present the lesson.

```yaml
---
title: A useful lesson
layout: document
---
```

## Images and code

Markdown images are centered automatically and remain responsive. Fenced code blocks receive syntax highlighting when their language is supported.
