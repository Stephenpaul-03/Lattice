# What is Lattice?

Lattice is a focused shell for learning content. It turns folders of markdown into calm, searchable workspaces with a shared navigation model.

## The basic idea

The application owns the reading experience while each subject owns its content. This keeps the interface consistent and lets every subject have its own vocabulary and learning path.

## The building blocks

Every subject needs a sidebar JSON file, an overview markdown file, and markdown files for the topics listed in its categories. The app checks those files at runtime and only shows lessons that exist.
