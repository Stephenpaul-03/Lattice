# Lattice Template

This subject is a small, practical guide to how **Lattice** works. Copy it when you want to start a new subject and use it as a reference while building your own lessons.

## What Lattice is

Lattice is a markdown-powered learning app. Each subject is a self-contained workspace with its own sidebar, overview page, categories, and lessons.

## What you can build

* Focused documentation and learning paths written in markdown.
* Multiple subjects that can be switched without leaving the app.
* Search across every subject and recently visited lessons.
* Concept checks with one or more questions per lesson.
* Split or document-style lesson layouts, responsive images, syntax-highlighted code, and downloadable pages.
* Light and dark themes with a system-aware visual identity.

## Where to begin

Use the sections in the sidebar to learn the content format, understand how workspace files are discovered, and see the features available to each lesson.
