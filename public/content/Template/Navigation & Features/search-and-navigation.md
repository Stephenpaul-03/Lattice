# Search and Navigation

Use the sidebar to move through the active workspace. The breadcrumb bar keeps the current category and lesson visible while you read.

## Search

The search palette opens from the Search button or `Cmd + K`. It searches the topics discovered across every subject and keeps a short list of recently visited pages.

## App home

The Home icon in the breadcrumb returns to the app-level workspace picker. The workspace overview remains available from the sidebar as **Overview**.
